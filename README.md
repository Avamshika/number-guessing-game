# 🎯 Number Guessing Game

A simple and interactive Number Guessing Game built using **HTML**, **CSS**, and **JavaScript**. The game generates a random number, and the player must guess it with the help of hints until the correct number is found.

## 🚀 Live Demo

🔗 https://avamshika.github.io/number-guessing-game/

---

## 📌 Features

* 🎲 Random number generation
* 🔢 User input validation
* 📈 "Too High" and 📉 "Too Low" hints
* 🏆 Winning message
* 🎨 Clean and responsive user interface
* ⚡ Fast and lightweight gameplay

---

## 🎮 How to Play

1. Enter a number in the input field.
2. Click the **Guess** button.
3. The game will compare your guess with the generated number.
4. You will receive hints:

   * 📈 Too High
   * 📉 Too Low
   * ✅ Correct Guess
5. Continue guessing until you win.
